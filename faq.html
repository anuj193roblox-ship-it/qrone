QR code FAQ

Do QR codes expire?

A static QR code never expires. It is just your address drawn as a picture. A dynamic QR code can stop working, because it depends on a company's server forwarding each scan to your page. If that company turns the forwarding off, the printed code stops reaching your page.

What is the difference between static and dynamic?

A static code stores your real web address inside the pattern. A dynamic code stores a short link owned by the QR service, and that service redirects to your page. Dynamic codes let you change the destination later and count scans, but you depend on the service staying active.

How can I tell which kind I have?

Use the checker. It reads the code and shows whether it points straight at a website or at a known QR-vendor short link. You can also scan the code with your phone and look at the address it shows before opening it.

Why would a dynamic code stop working?

Common reasons are a trial or subscription ending, a vendor changing its plans, or a vendor closing down. Several vendors say on their own help pages that codes are deactivated after a trial. The checker links to the vendor's page for each domain it recognises.

Can I change where a static code points?

No. The address is part of the picture, so a different destination needs a new code. If you may need to change the destination after printing, you need a dynamic code, ideally on a domain you control.

Does the checker upload my image?

No. The image is read on your device and is never sent anywhere. See the privacy page.

The checker says "unknown short link". What does that mean?

The code goes through a link shortener or redirect service that isn't on our list. We can't say who runs it or what happens when an account ends. If you made the code, check the account behind it.
