About {{NAME}}

A QR code is only as permanent as the thing it points at. Some QR generators make dynamic codes: the printed pattern holds the vendor's short link, and the vendor's server forwards each scan to your page. That lets you edit the destination later, but it also means the vendor can stop the forwarding, for example when a trial or subscription ends.

{{NAME}} starts with two free tools:

  • A static QR generator. Your address is stored in the code itself. Nothing sits in the middle, so there is nothing to switch off.
  • A checker. Drop in a QR code image and see whether it points straight at a website or through a vendor's short link. The image is read on your device and never uploaded.

Where this is going

We are building dynamic codes on your own domain, paid once, with an export of every redirect so your codes keep working even if this service disappears. It is not available yet.

How the checker decides

It compares the code's domain with a list of known vendor short-link domains. Each entry on that list links to the vendor's own help or pricing page, so you can read what the vendor says for yourself. A domain is only added when there is a source for it. If a code isn't on the list, the checker says so and does not guess.
