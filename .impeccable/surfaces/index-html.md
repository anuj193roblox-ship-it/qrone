# Surface: QrOne site (home with Make | Check, dashboard, sign-in, about, privacy, FAQ)

Scope: every page. Mode: Operate (the tools and dashboard), with Read pages in the same system.
Audience: small business owners about to print, or who just found a dead printed code. Job: make a code in about 10 seconds. Checking is the second tab.
Direction source: user-pinned reference (2026-11-25): a calm, dark trial page with one blue accent, a big friendly two-line headline, soft rounded panels and a "what happens when" timeline. It replaces the letterboard world fully. Dark only.
Refused from the reference: the countdown timer (fake urgency), invented testimonials, and emoji used as icons.

## Direction contract

THESIS: Calm confidence. One quiet dark room with a single blue light on the action that matters, so a nervous shop owner feels the code is safe before reading a word. It refuses busy QR-generator pages full of ads and badges, and it refuses fake urgency.

OWN-WORLD: Near-black ground (#0b0c0f), raised panels a step lighter (#14161b) with 1px borders (#262a33) and 16–20px radii. Text is off-white (#f4f5f7) and grey (#a6acb8). The single accent is blue: #3563f0 behind white text on the primary pill button, and #6b95ff for the second headline line and links. Figtree throughout: 800 for headlines, 600–700 for labels and buttons, 400 for text. Line icons are drawn in SVG at 1.75 stroke. Green, amber and red appear only for checker verdicts and code states.

STORY: The visitor reads "QR codes that / never expire.", sees the tool card beside it, types an address and downloads. The timeline explains, without a lecture, why the code will still work in years. On the Check tab, the verdict appears as a card with a coloured state pill.

FIRST VIEWPORT: A slim top bar (QrOne on the left; How it works and Privacy on the right). Below it, on desktop: left column with the two-line headline at about 4rem, one short subline, and the "What happens after you print" timeline; right column with the tool card (Make | Check pill switch, address field, type chips, live code and the blue Download PNG pill). On a phone: headline, then the tool card, then the timeline.

FORM: User-pinned reference, not a rolled candidate. seed: none (unavailable). Signature move: the "what happens when" timeline, used on the home page to show what happens to a code over time, so the product's promise is shown as a sequence rather than claimed.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
