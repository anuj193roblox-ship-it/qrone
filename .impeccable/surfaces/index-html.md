# Surface: QrOne free tools (home: Make | Check)

Scope: index.html (home with both tools), plus about.html, privacy.html and faq.html in the same system. Mode: Operate.
Audience: small business owners about to print, or who have just found a dead printed code. Job: make a code in about 10 seconds. Checking is the secondary tab.
Constraints: one tool on screen at a time (Make | Check switch). Little text. Must not read as a generic SaaS template or as an ad-heavy QR site. Everything stays on the device.

## Direction contract

THESIS: The tool speaks like a shop window: a few big words set on a felt letterboard say what is happening now. Everything else is quiet working space. It refuses the category default of a centred hero, grey card and blue tabs.

OWN-WORLD: Oak-framed black grooved felt (#1d1d1b, 1px groove every 14px) carrying push-in letters in Big Shoulders Display caps, widely tracked. Working ground is off-white (#f7f6f2) with ink #1d1d1b. Areas divide with 1px hairline seams (#dcd8cf), never shadows or cards. Letter yellow (#f2c230) is only for the primary action. Verdict letters appear only on the board: red (#ff6b57) for a code that can be switched off, orange (#ff9a5c) for an unknown link, and green (#8fd19e) for no vendor in the middle. The QR preview is the only pure black. Body text is Figtree. Each text role has one fixed size.

STORY: The visitor sees "MAKE A CODE THAT NEVER EXPIRES", types an address, sees the code and downloads it. On Check, they drop an image and the board re-sets itself to the verdict.

FIRST VIEWPORT: The board is about the top third: nav row (QRONE, How it works, Privacy), two lines of board letters, and the Make | Check switch sitting on the board's bottom edge as tabs. Below, two columns split by one continuous seam. The left column holds the type switch, the large address field directly under it, and a collapsed options row. The right column holds the live code with a yellow Download PNG and an SVG button. On a phone this stacks in source order (board, type switch, field, code, download, options), so screen order and keyboard order always match. This order was revised after the finish review.

FORM: Letterboard, candidate 7 of 7 on the ordered list. seed: be1fa0948dd1961a. Signature move: the board is the status display. Its letters drop into the grooves one by one when the job or verdict changes, and they appear instantly under reduced motion.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
